# WhatsApp brand icon

The recognizable WhatsApp SVG glyph is from the locally installed Font Awesome Free 6.7.2 brand icon (`@fortawesome/fontawesome-free/svgs/brands/whatsapp.svg`). Its path is retained, rendered in the button’s current text colour, and included inline in the contact button and existing floating shortcut.
